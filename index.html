Apa itu DOM

DOM adalah singkatan dari Document Object Model. Ketika sebuah halaman HTML dibuka di browser, browser mengubah seluruh tag HTML itu menjadi struktur data yang bisa diakses dan diubah lewat JavaScript. Struktur inilah yang disebut DOM.

Karena HTML sudah diubah menjadi struktur data, JavaScript bisa mencari elemen tertentu, membaca isinya, mengubah teksnya, atau bahkan menghapusnya. Semua fungsi yang dibahas di halaman ini, yaitu getElementById, querySelector, dan querySelectorAll, adalah cara-cara untuk mencari elemen di dalam DOM.

getElementById

Mengambil satu elemen berdasarkan atribut id

Fungsi ini dipakai ketika sebuah elemen HTML sudah diberi atribut id, dan id itu bersifat unik, artinya hanya ada satu elemen dengan id tersebut di seluruh halaman. getElementById akan mencari elemen dengan id yang cocok dan mengembalikan elemen itu langsung, bukan berupa daftar.

// mengambil tombol dengan id="hitungBtn"
const hitungBtn = document.getElementById("hitungBtn");

// mengambil span yang menampilkan angka total
const totalSpan = document.getElementById("total");

Di dalam kode kasir, ada empat pemanggilan getElementById, yaitu untuk tombol hitung, tombol reset, teks total, dan teks rincian. Semuanya diambil di bagian awal script, lalu disimpan ke dalam variabel supaya bisa dipakai berulang kali tanpa perlu mencari elemen itu lagi.

querySelectorAll

Mengambil semua elemen yang cocok dengan sebuah selector CSS

Berbeda dari getElementById yang hanya mengambil satu elemen lewat id, querySelectorAll menerima selector CSS apa saja, misalnya nama class, nama tag, atau kombinasi keduanya, lalu mengembalikan semua elemen yang cocok dalam bentuk kumpulan yang disebut NodeList.

// mengambil SEMUA checkbox yang punya class "menu"
const semuaMenu = document.querySelectorAll(".menu");

Pada kode kasir, ada empat checkbox menu, dan semuanya diberi class yang sama, yaitu menu. Baris kode di atas mengambil keempat checkbox itu sekaligus dan menyimpannya sebagai satu kumpulan bernama semuaMenu. Kumpulan inilah yang nanti diperiksa satu per satu untuk mengetahui menu mana saja yang dicentang pengguna.

Perbedaan penting. getElementById mengembalikan satu elemen tunggal, sedangkan querySelectorAll selalu mengembalikan sebuah kumpulan, walaupun elemen yang cocok hanya satu.

querySelector

Mengambil satu elemen pertama yang cocok dengan selector

querySelector mirip dengan querySelectorAll karena sama-sama menerima selector CSS. Bedanya, querySelector berhenti mencari begitu menemukan elemen pertama yang cocok, lalu langsung mengembalikan elemen tunggal itu saja, bukan kumpulan.

// mengambil checkbox PERTAMA yang punya class "menu"
const menuPertama = document.querySelector(".menu");
console.log("Menu pertama harganya: " + menuPertama.dataset.harga);

Di kode kasir, baris ini dipakai sebagai contoh saja, untuk menunjukkan bahwa querySelector hanya mengambil elemen pertama yang ditemukan di dalam HTML, yaitu checkbox Nasi Goreng. Harganya kemudian ditampilkan di console browser lewat console.log.

addEventListener

Menjalankan sebuah fungsi ketika sebuah peristiwa terjadi pada elemen

Elemen yang sudah diambil dengan getElementById atau querySelector belum bisa berbuat apa-apa dengan sendirinya. addEventListener dipakai untuk memberi tahu elemen itu, agar ketika ada peristiwa tertentu terjadi, misalnya diklik, sebuah fungsi tertentu akan dijalankan.

hitungBtn.addEventListener("click", function() {
  // kode di dalam sini dijalankan setiap kali tombol diklik
});

Parameter pertama, yaitu "click", menentukan jenis peristiwa yang ditunggu. Parameter kedua adalah fungsi yang akan dijalankan saat peristiwa itu terjadi. Pada kode kasir, ada dua addEventListener, satu terpasang pada tombol Hitung Total, dan satu lagi pada tombol Reset.

dataset

Membaca atribut khusus yang diawali data- pada sebuah elemen

Setiap checkbox menu diberi atribut tambahan bernama data-harga, contohnya data-harga="15000". Atribut yang diawali dengan data- ini disebut atribut kustom, dan JavaScript bisa membacanya lewat properti dataset.

<input type="checkbox" class="menu" data-harga="15000">

// dibaca lewat JavaScript
item.dataset.harga  // hasilnya "15000", masih berupa teks

Nama atribut data-harga, ketika dibaca lewat dataset, menjadi dataset.harga. Aturan penulisannya, tanda hubung dihilangkan dan huruf sesudahnya tidak perlu dikapitalkan karena hanya ada satu kata setelah data-.

parseInt

Mengubah teks angka menjadi angka yang bisa dihitung

Nilai yang diambil lewat dataset selalu berupa teks, walaupun isinya terlihat seperti angka. Teks tidak bisa dijumlahkan secara matematis, karena tanda plus pada dua teks hanya akan menggabungkannya, bukan menjumlahkannya. Oleh karena itu, parseInt dipakai untuk mengubah teks itu menjadi angka bulat.

const harga = parseInt(item.dataset.harga);
// "15000" (teks) menjadi 15000 (angka)
Kenapa ini penting. Kalau parseInt tidak dipakai, "15000" + "12000" akan menghasilkan teks "1500012000", bukan angka 27000. Ini adalah kesalahan yang sering terjadi ketika data diambil langsung dari HTML.

forEach

Menjalankan sebuah fungsi untuk setiap elemen di dalam sebuah kumpulan

Karena querySelectorAll mengembalikan kumpulan berupa NodeList, kumpulan itu perlu diperiksa satu per satu untuk mengetahui bagian mana yang dicentang. forEach adalah cara untuk melakukan itu, yaitu menjalankan satu fungsi yang sama untuk tiap elemen di dalam kumpulan, secara berurutan.

semuaMenu.forEach(function(item) {
  if (item.checked) {
    // item adalah satu checkbox yang sedang diperiksa
  }
});

Pada kode kasir, forEach dipakai dua kali. Pertama, di dalam tombol Hitung Total, untuk memeriksa checkbox mana yang berstatus checked lalu menjumlahkan harganya. Kedua, di dalam tombol Reset, untuk mengatur ulang semua checkbox menjadi tidak tercentang.

toLocaleString

Memformat angka menjadi format ribuan sesuai suatu wilayah

Angka total yang sudah dihitung masih berupa angka polos, misalnya 27000. Supaya lebih mudah dibaca sebagai uang, angka itu perlu diberi titik pemisah ribuan. toLocaleString("id-ID") mengubah angka mengikuti format penulisan Indonesia, sehingga 27000 menjadi 27.000.

total.toLocaleString("id-ID")
// 27000 menjadi "27.000"

Alur kerja lengkap program

Urutan yang terjadi ketika tombol Hitung Total diklik

  1. Peristiwa klik terdeteksi oleh addEventListener pada hitungBtn, dan fungsi di dalamnya mulai dijalankan.
  2. Dua variabel disiapkan, yaitu total yang diisi angka 0, dan daftarPilihan yang berupa array kosong untuk menampung nama menu yang dipilih.
  3. forEach berjalan pada semuaMenu, memeriksa checkbox satu per satu.
  4. Untuk setiap checkbox yang berstatus checked, harganya dibaca lewat dataset.harga, diubah menjadi angka lewat parseInt, lalu ditambahkan ke variabel total.
  5. Nama menu diambil dari teks label, bagian sebelum tanda kurung buka, kemudian dimasukkan ke dalam daftarPilihan.
  6. Setelah forEach selesai memeriksa semua checkbox, program mengecek apakah total masih 0. Jika ya, artinya belum ada menu yang dipilih, dan pesan itu yang ditampilkan.
  7. Jika total lebih dari 0, angka total diformat dengan toLocaleString dan ditampilkan di totalSpan, sementara daftar nama menu digabung dengan koma dan ditampilkan di rincianP.

Tombol Reset bekerja lebih sederhana. forEach dipakai lagi untuk mengubah properti checked pada setiap checkbox menjadi false, lalu teks total dan rincian dikosongkan kembali.

Kode lengkap

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Kasir Sederhana</title>
</head>
<body>
    <h1>Kasir Warung</h1>
    <hr>

    <h3>Pilih Menu:</h3>
    <label><input type="checkbox" class="menu" data-harga="15000"> Nasi Goreng (Rp15.000)</label><br>
    <label><input type="checkbox" class="menu" data-harga="12000"> Mie Ayam (Rp12.000)</label><br>
    <label><input type="checkbox" class="menu" data-harga="8000">  Es Teh (Rp8.000)</label><br>
    <label><input type="checkbox" class="menu" data-harga="5000">  Kerupuk (Rp5.000)</label><br>

    <br>
    <button id="hitungBtn">Hitung Total</button>
    <button id="resetBtn">Reset</button>

    <h3>Total: <span id="total">Rp0</span></h3>
    <p id="rincian"></p>

    <script>
        // ==========================================
        // 1. getElementById -> ambil elemen TUNGGAL
        // ==========================================
        const hitungBtn = document.getElementById("hitungBtn");
        const resetBtn  = document.getElementById("resetBtn");
        const totalSpan = document.getElementById("total");
        const rincianP  = document.getElementById("rincian");

        // ==========================================
        // 2. querySelectorAll -> ambil SEMUA menu
        // ==========================================
        const semuaMenu = document.querySelectorAll(".menu");

        // ==========================================
        // 3. querySelector -> ambil SATU menu (contoh)
        // ==========================================
        const menuPertama = document.querySelector(".menu");
        console.log("Menu pertama harganya: " + menuPertama.dataset.harga);

        // ==========================================
        // FUNGSI: Hitung total belanja
        // ==========================================
        hitungBtn.addEventListener("click", function() {
            let total = 0;
            let daftarPilihan = [];

            // Loop semua menu, cek mana yang dicentang
            semuaMenu.forEach(function(item) {
                if (item.checked) {
                    const harga = parseInt(item.dataset.harga);
                    total += harga;
                    // Ambil label teksnya (buang bagian harga)
                    const nama = item.parentElement.textContent.split("(")[0].trim();
                    daftarPilihan.push(nama);
                }
            });

            // Tampilkan hasil
            if (total === 0) {
                totalSpan.textContent = "Rp0";
                rincianP.textContent = "Belum ada menu yang dipilih.";
            } else {
                totalSpan.textContent = "Rp" + total.toLocaleString("id-ID");
                rincianP.textContent = "Menu dipilih: " + daftarPilihan.join(", ");
            }
        });

        // ==========================================
        // FUNGSI: Reset semua pilihan
        // ==========================================
        resetBtn.addEventListener("click", function() {
            // querySelectorAll dipakai lagi untuk loop
            semuaMenu.forEach(function(item) {
                item.checked = false;
            });
            totalSpan.textContent = "Rp0";
            rincianP.textContent = "";
        });
    </script>
</body>
</html>

Kode ini bisa disalin ke dalam sebuah file baru, misalnya diberi nama kasir.html, lalu dibuka langsung lewat browser tanpa memerlukan server atau instalasi apa pun.
